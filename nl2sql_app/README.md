# Natural Language to SQL Query Generator (Streamlit)

A Streamlit app that turns plain-English (or spoken) requests into SQL,
explains the query in plain language, and shows a visual, color-coded
breakdown of the SQL syntax. Includes login/signup, SQL learning tools,
saved queries, and feedback — all backed by a local SQLite database.

## 1. Setup

```bash
# from the project folder
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

pip install -r requirements.txt
```

`SpeechRecognition`, `pydub`, and `anthropic` are optional — the app
works fully without them (Voice-to-SQL falls back to manual transcript
entry, and Text/Voice-to-SQL use a built-in rule-based engine instead
of the AI-assisted mode).

## 2. Run

```bash
streamlit run app.py
```

Then open the URL Streamlit prints (usually `http://localhost:8501`).

## 3. First use

1. Sign up for an account (stored locally in `app_data.db`, created
   automatically on first run).
2. Log in.
3. Use the sidebar to navigate between Text-to-SQL, Voice-to-SQL, SQL
   Learning (Notes / Practice / Validation / Text-Based Practice),
   Saved Queries, Feedback History, and FAQ.

## 4. Optional: AI-assisted mode

By default, SQL is generated by a built-in rule-based engine (no
external calls, works offline). If you'd like more flexible natural-
language understanding, paste an Anthropic API key into the "AI Mode"
box in the sidebar. When present, requests are sent to Claude; if that
call ever fails for any reason (missing key, no network, bad
response), the app automatically and silently falls back to the
rule-based engine, so it never crashes.

## 5. Project structure

```
nl2sql_app/
├── app.py              # Streamlit UI, routing, session/auth flow
├── database.py         # SQLite layer: users, saved queries, feedback
├── nl2sql_engine.py     # Natural language -> SQL conversion logic
├── sql_visualizer.py    # Builds the color-coded syntax breakdown + flow diagram
├── requirements.txt
└── README.md
```

## 6. Notes on the background image

The hero banner on the login/signup screen currently uses a stock
database-themed image URL as a placeholder. To use your own SQL/
database image, replace the URL inside the `.hero-banner` CSS rule at
the top of `app.py` with a local path, e.g.:

```css
background-image: url('app/static/sql_hero.jpg');
```

(Streamlit serves files placed in a `static/` folder next to `app.py`
when you enable `enableStaticServing` in `.streamlit/config.toml`.)

## 7. Extending the rule-based NL→SQL engine

`nl2sql_engine.py` is intentionally modular — each SQL clause
(`WHERE`, `JOIN`, `GROUP BY`, `ORDER BY`, `HAVING`, `LIMIT`, etc.) has
its own small extraction function, so you can tune or extend pattern
matching for your own phrasing/vocabulary without touching the rest of
the app.
